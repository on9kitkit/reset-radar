# Security and privacy

## Boundaries

Reset Radar is a local macOS app, not an App Sandbox container. It runs as the signed-in user and intentionally launches a trusted local Codex CLI and user-approved status-line commands. It is not designed to defend against malicious software already running as that same macOS user. Choose executables, configuration files and exporters you trust.

The app has no listening server, telemetry collector, remote update mechanism or bundled credentials. Its direct background HTTPS destinations are the fixed ModelYard feed, the OpenAI Responses endpoint in the selected OpenAI API mode, and `api.x.com` in the selected authenticated X mode. The default Codex checker launches the installed CLI, which connects to OpenAI using its existing ChatGPT sign-in and uses hosted web search. Original X and provider documentation links open only when clicked. The feed is third-party, indirect evidence.

Optional OpenAI API requests include an in-memory key read from macOS Keychain. Codex checks require a ChatGPT account and do not extract, copy or inject its sign-in tokens. The three checkers never fall back to each other. Network requests use ephemeral sessions, no cookie jar or disk cache, ordinary platform TLS validation, no redirects, timeouts and a 2 MB decoded-response limit. Error messages do not echo remote bodies or credentials. `store: false` is sent to OpenAI; provider-side retention still follows the API account’s applicable policies.

The key is never included in this source package or quota files. Keychain reads, writes and removal run away from the UI thread; controls wait while the operation is pending. Removing a key disables API monitoring and cancels a pending API request before removing its local credential; it does not disable the Codex plan checker. It cannot undo an already-billed request.

## Input handling

Quota JSON reads are bounded to 256 KiB and accept only regular files. Exported provider IDs, percentages, dates, labels, counts and window IDs are validated. Missing or stale data does not become a fabricated 100% balance. Built-in readers save only explicitly selected quota fields. They forward the original payload to the pre-existing status-line command, as that command already received it; they do not persist prompts, project paths, email addresses, transcripts or tokens from the payload.

Local quota files, news cache and connection backups are written atomically using owner-only temporary files. Connection backups preserve the previous status-line command, which may itself contain sensitive user configuration; these backups remain local. Settings symlinks are resolved, unrelated settings are retained, managed-hook policy gates are respected and corrupt backups are kept for recovery. Configuration files should not be edited concurrently during connection/disconnection; JSON file updates cannot offer a transaction across third-party editors that do not cooperate with locks.

The original status-line command is trusted existing user configuration, not provider-supplied code. The bridge invokes that command through the shell with the same input; generated paths are shell-quoted. It stops the direct child process after three seconds. Descendants created by a user command can outlive that child; commands that start background jobs remain the user’s responsibility. Interactive Codex reads allow up to eight seconds per candidate and try at most three candidates for launch or compatibility failures; the standalone live diagnostic allows 25 seconds. Account checks discard identity fields and distinguish sign-in, API-only access, network failures and invalid responses.

RSS parsing rejects DTDs and entity declarations, disables external entities and bounds entries and field lengths. Retrieved titles and posts are treated as untrusted evidence in the model prompt. The web-search modes permit hosted web search only. In authenticated X mode the model receives the retrieved original public post text with every tool, including web search, disabled. Codex checks ignore user configuration, disable project instructions, use a private temporary working directory, disable local execution and integration tools, and run without persisting a session rollout. They reject nonempty global AGENTS instructions and verify that inherited MCP integrations are disabled. Managed settings remain authoritative and can prevent a check. The reused CLI profile can still supply installed-skill catalog names, paths and descriptions as ordinary model context; the app does not claim a wholly isolated prompt. A bounded deadline, bounded output and cancellation protect the companion from a stuck subprocess. Temporary request material is removed after the check. The CLI keeps its normal responsibility for existing sign-in storage; Reset Radar does not read that storage. X result URLs require the exact HTTPS host, an allowlisted author (thsottiaux, reach_vb, OpenAI or OpenAIDevs) and numeric post route, with no credentials, custom port, query or fragment. Direct confirmation requires readable original-page evidence paired with an explicit current reset finding; search sources or citations alone are insufficient. Report content and verification quality are displayed separately. A current indirect reset report may show “Reset reported” with “Original unavailable”, but remains yellow and cannot supply a confirmed countdown. Inaccessible or ambiguous originals do not become directly verified merely because a report exists. No model-assisted classifier can guarantee error-free news interpretation.

Recent web-search coverage is generated from completed hosted tool calls with actual account-specific query strings and explicit UTC date bounds. A model-provided claim of coverage is not accepted. Failed calls, missing result metadata and error-page-only results do not count; completed empty or historical results can establish only a search-scoped no-announcement result. All four accounts must have matching receipts. The versioned cache revalidates the receipt set, backend, date window and contradictory current observations; it never promotes an old blocked review into green. A historical original-page access failure does not invalidate independent successful recent searches. This does not assert that the search index contains every X post or that no reset will occur.

## Authenticated X source

The X app-only Bearer Token is stored under the separate macOS Keychain service `local.resetradar.x`. Saving the token is an explicit action labelled **Save token & enable paid X reads** with pricing, resource caps and console spending controls shown before it. No X password or API secret is requested. The token exists in memory only for Keychain and direct HTTPS authorization; it never enters the Codex prompt, a URL, log, source file or news cache. A per-operation token hash prevents accidentally reusing a snapshot after a token change. Errors use fixed, sanitized messages.

Authenticated reads use a fixed `https://api.x.com/2` origin with no redirects, cookies or disk HTTP cache. The four expected profile names must match unique numeric IDs. Post authors must match the resolved timeline owner, timestamps must fall within the fixed 48-hour window, and long-form text is preferred over abbreviated text. Partial errors, missing accounts, suspicious truncation, excess content, repeated cursors, request limits or unfinished pagination reject complete coverage. The client has a 150-second retrieval deadline, per-request deadlines, a 100-post ceiling, a 512 KB aggregate-text ceiling and cancellation. Current and legacy field spellings are handled only through a narrowly recognized parameter-error fallback, never by accepting missing required evidence.

A user-selected post-read allowance and a separate 12-user-lookup allowance are reserved before calls, including retries and compatibility fallbacks. Only validated successful responses refund unused resources. The console remains the authority for monetary limits. Successful snapshots are reused during analysis retries; full post collections are not persisted. A private 24-hour cache stores public account IDs only. Saved findings include a bounded exact excerpt, allowed source link, model identity when available, and client-generated coverage metadata. A model cannot assert that missing pages were fetched. Clear negation/speculation/routine wording cannot become red through the model label alone; unsupported model-converted timestamps cannot create a countdown. Interpretation still has limits, especially for images, links, language and missing thread context.

## Reporting and release

Do not paste keys, account data or full status-line payloads into public issues. If the future GitHub repository enables private vulnerability reporting, use its Security tab; otherwise contact the maintainer privately through a channel they provide. No reporting address has been invented for this unpublished project.

Before a public binary release, use a Developer ID certificate and notarization, test on a clean Mac, exercise the supported macOS versions and Intel hardware, and validate live Claude/Antigravity subscription connections. The current work is ready for source review, not a certification of zero bugs or a penetration test.
