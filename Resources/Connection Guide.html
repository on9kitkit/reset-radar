Codex

Sign in inside Codex or the Codex section of ChatGPT, then use the connection action in Reset Radar. The widget detects both current and older bundled CLI layouts in system and personal Applications folders, as well as standalone CLI locations. It remembers a working installation and can try another when an executable is incompatible. Use Connect account to retry. For a different installation, expand Connection options and choose Find Codex again or Choose Codex app or CLI. CLI users can sign in using codex login. See the official app guide.

Claude Code and Antigravity CLI

  1. Install and sign in to the harness with your own account.
  2. Select it in Reset Radar’s Connections screen and click Connect usage.
  3. Use the harness normally. The widget reads the quota values it reports.

Claude Code supplies five-hour, weekly and gateway spend-limit fields when available. Subscription windows generally require Pro or Max; API-only accounts can omit them. Data appears after the first API response. Current documentation calls for Claude Code v2.1.251 or later for the rate-limit status line. See Claude Code’s status-line documentation.

Antigravity’s CLI supplies per-model quota fractions and absolute reset times through its status line. Reset Radar uses the absolute times rather than turning a cached relative duration into a moving deadline. See Antigravity’s status-line documentation.

Setup changes the selected harness’s statusLine command. An existing command continues to receive its input and render its output, within a three-second execution budget; other status-line options are preserved. Reset Radar saves the previous status-line configuration locally. Disconnect from widget restores it if Reset Radar still owns that setting, and preserves newer changes made by another tool.

Standard locations are ~/.claude/settings.json and ~/.gemini/antigravity-cli/settings.json. Choose Custom settings or exporter → Choose settings file for another location. Project or managed settings can override a user status line; Reset Radar does not override a policy that disables local commands.

When quota is unavailable

Connecting a reader does not authenticate an account or create a subscription. A connection can be waiting for the harness, connected with no quota reported, stale, or unable to read its file. Use the harness to get a new report. After five minutes without one, values are marked as last reported and the compact card asks for an update. A passed reset time is never treated as proof that quota refilled.

Other mascots keep their chosen colours. Only Codex’s news monitor changes between green, yellow and red.

Codex reset news

News monitoring is separate from your Codex quota connection. Reset reported means a review found an explicit reset claim in search results or a public mirror. The verification badge tells you whether the original X post was readable: Original unavailable means access was blocked or the original could not be read; Original not verified means the report is still indirect. The card keeps the headline and available source links, so yellow can contain useful reset news.

Green means a successful current-source search found no current reset announcement. Yellow means a reported reset awaiting direct verification, unclear news, an unavailable check or a stale review. Red requires a current explicit reset announcement verified against the original X post. An X access block such as HTTP 403 cannot be treated as direct verification. Unverified reports do not add an announced reset time to the countdown, and public news does not prove that your account refilled.

  1. Open the menu-bar paw and choose News settings….
  2. Choose Codex · web search only. Sign in to Codex with ChatGPT if needed; the widget uses that existing sign-in.
  3. Set Check every to 1 hour, enable Enable scheduled news checks and choose Check news now.

The Codex checker counts toward your Codex plan usage and needs no separate API key. It never falls back to a paid OpenAI API call. Keep Reset Radar running and your Mac awake for scheduled checks. Temporary failures receive at most two retries; the screen shows the reason and next retry. The previous successful review stays visible with its actual age.

For an optional separately billed checker, select OpenAI API · billed separately. Keep your saved key or enter one in the secure field. This uses gpt-6-luna with web search and is billed to your OpenAI API project. Both credential-based modes use macOS Keychain. Settings show the requested CLI model separately from the response model returned by the API.

Connect X directly

  1. Open News settings… → X API + Codex plan · direct posts.
  2. Open X Developer Console, create an app and copy its Bearer Token. Review X’s pricing, add credits if required and set a spending limit. Purchases and auto-recharge are your choice.
  3. Paste the token into the widget’s secure field and choose Save token & enable paid X reads. Do not paste the token into a chat or public issue.
  4. Keep Codex signed in with ChatGPT. X supplies original posts; GPT-6 Luna reads them using your Codex plan with web search disabled.

The app reads original post text from all four public account timelines for the previous 48 hours, including replies, with at most 100 posts per check. Images, videos and linked-page content are not analyzed; green is scoped to the returned post text. Any missing page or partial response prevents a complete result. The token is stored in macOS Keychain, goes only to api.x.com and is never given to the model. No X password or API secret is needed.

The default cap is 200 post reads per UTC day plus up to 12 user lookups. At current listed prices this corresponds to up to $1.12 daily before any X deduplication. Requests reserve possible resource reads before sending; failures can retain that reservation. Busy feeds may pause checks early. You can change the post-read cap in the same screen; X’s console spending limit controls your actual bill. Full timeline rechecks can cost more than an incremental monitor. See X’s current pricing before choosing a cap.

Rejected tokens, credit/access problems, rate limits and local budget pauses have separate messages. A replacement token can be entered in the same secure field. Removing it stops direct X checks. There is no automatic fallback to another checker. Authenticated API access does not guarantee X uptime, advance notice of a reset or error-free model interpretation.

All checkers monitor @thsottiaux, @reach_vb, @OpenAI and @OpenAIDevs. Attempts, including retries, share a 48-attempt daily cap and a one-minute manual-check cooldown. Reviews become stale after two hours. An inaccessible source cannot become a verified result merely because the check finished.

Usage-file connections

For Grok, Cursor and Muse, select Choose usage file and link a JSON file written by a compatible exporter. Reset Radar watches the selected file every five seconds. This is a file connection, not a provider login or a built-in exporter. Cursor’s Spending dashboard and Grok’s Usage settings remain the providers’ documented places to inspect account quota.

For integration authors: JSON format

The following is illustrative data, not a real account reading. Write the provider’s actual measurement timestamp and actual available fields. provider must match the selected mascot: claude, antigravity, grok, cursor or muse.

{
  "provider": "grok",
  "observedAt": 1789225200,
  "windows": [
    {
      "id": "weekly",
      "name": "Weekly",
      "remainingPercent": 75,
      "resetsAt": 1789830000
    }
  ]
}
  • Timestamps use Unix seconds. Do not update observedAt until there is a new measurement.
  • Percentages represent remaining quota, from 0 to 100. Omit missing percentages or reset times; each window needs at least one. Use an empty windows array when quota is unavailable.
  • Window IDs must be unique. Names and IDs are limited to 120 characters; there may be at most 64 windows.
  • Optional bankedResets and creditExpiry are accepted only when your source actually supplies them.
  • Write atomically so the reader never sees half a document. Files are limited to 256 KB. Extra fields are ignored and never forwarded to the news API.
  • Exports must come from an account the user is authorized to access. Reset Radar does not collect browser cookies or bypass provider authentication.

Privacy and maintenance

The built-in readers save only quota windows, timestamps and optional reset-credit information. They do not save the status-line payload’s prompts, project paths, email addresses, transcripts or sign-in tokens. Your pre-existing status-line command still handles the same input it handled before.

Reader files and restoration metadata live under ~/Library/Application Support/ResetRadar/connections, separately for each macOS user. A small executable copy there keeps the connection working if the main app is moved. Existing managed readers are refreshed when the widget starts. If setup is missing or another tool changed the status line, the connection screen explains the issue; use Reconnect usage to repair it. Users sign out in the provider’s app; disconnecting the widget does not sign out the provider.

Codex news is optional and separate. The Codex checker reuses the existing ChatGPT sign-in without copying credentials. The optional OpenAI API key and X Bearer Token stay in separate macOS Keychain entries; connecting a quota reader does not enable paid API calls. Reset Radar supplies public news queries, titles and URLs. Codex may also include its normal installed-skill catalog metadata from your profile. Global AGENTS instructions or integration settings that cannot be safely disabled block a plan check with an explanation. Personal harness quota stays local, and API response storage is disabled. Replacing this locally signed app may prompt macOS to ask you to approve Keychain access again in its secure prompt.

Release status

This build includes Apple Silicon and Intel executables and targets macOS 13 or later. It is locally signed, not Apple-notarized; Developer ID signing and notarization remain necessary for a frictionless public release. Claude and Antigravity setup, parsing, status-line forwarding and restoration were tested with isolated documented-format fixtures; live subscription tests still require those accounts.
